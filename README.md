# 期末考试复习资料

本仓库用于整理和保存我在本科阶段为**自己的期末考试**整理的课程复习资料。

这里的内容以实际课程期末复习为核心，主要包括任课老师划定或发放的**知识点、复习范围、题库**，以及我根据课程内容进一步整理的**参考答案与解析**。建立这个仓库的目的，是把不同课程的期末资料统一归档，方便考前复习、快速检索，也便于后续留存和回顾。

目前仓库收录了以下课程：

- **系统建模与分析设计（UML）**：[UML 期末知识点](系统建模与分析设计（UML）/UML期末知识点.md)。
- **软件项目管理**：[题库](软件项目管理/题库.md) · [答案与解析](软件项目管理/答案.md)。

## 内容说明

### 系统建模与分析设计（UML）

该部分是我根据大三下学期期末考试前老师划定的复习范围整理的知识点，主要涉及：

- 面向对象分析、设计与编程
- 抽象、封装、泛化
- UML 结构图与行为图
- 用例图
- 类及类之间的关系
- 面向对象设计原则
- 对象图与包
- 顺序图与通信图
- 状态机图与活动图
- 组件图与部署图
- RUP 统一软件开发过程

### 软件项目管理

该部分来源于大三下学期期末考试《软件项目管理》课程老师发放的题库。

我将题库重新整理为 Markdown，并另外整理了一份参考答案。内容包括：

- 单项选择题
- 判断题
- 填空题
- 简答题
- 综合应用题

其中，简答题和综合应用题的答案按照期末考试答题定位进行了精简，在尽量简短的同时保留主要得分点，方便考前记忆和实际书写。

## 说明

本仓库中的内容均为我为自己的期末考试进行的整理与归档，主要服务于个人课程复习。

题库、知识点等内容以课程老师提供的复习材料为基础；答案与解析为我结合课程内容整理的参考版本。如与课堂讲授内容或教师标准答案存在差异，应以任课教师的要求为准。

后续如有新的课程期末复习资料，也会继续按照课程文件夹的形式整理到本仓库中。
