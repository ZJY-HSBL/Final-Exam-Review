# 软件项目管理期末复习

本仓库用于整理我**大三下学期期末考试**课程《软件项目管理》的复习资料。

这份题库由课程老师在期末复习阶段发放，我将原始 PDF 中的题目完整整理为 Markdown，并在此基础上整理了对应的参考答案，便于在线阅读、检索和考前复习。

## 仓库内容

- `题库.md`：按照老师发放的原始 PDF 题库内容整理，保留题目、选项、填空、简答题和综合应用题。
- `答案.md`：我根据课程知识点整理的参考答案，包括选择题、判断题、填空题、简答题与综合应用题。

> 本仓库主要用于个人期末复习与知识整理。答案为本人整理的参考答案，如与课堂讲授内容或教师标准答案存在差异，请以课程教学要求为准。

## 仓库结构

```text
Software-Project-Management-Final-Review/
├── README.md
├── 题库.md
└── 答案.md
```

## 题库内容

题库主要包括以下五部分：

1. 单项选择题
2. 判断题
3. 填空题
4. 简答题
5. 综合应用题

其中，`题库.md` 直接依据老师发放的 PDF 题库整理；`答案.md` 为我整理的答案版本。客观题给出明确答案和简要解析；简答题与综合应用题按照期末考试答题定位进行了精简，在尽量简短的同时保留主要得分点。

## 使用建议

可以先使用 `题库.md` 独立练习，再对照 `答案.md` 检查。涉及 WBS、关键路径、PERT、项目生命周期、绩效域、估算方法等内容时，可结合课堂讲义一起复习。
