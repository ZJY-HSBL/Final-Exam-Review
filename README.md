# 软件项目管理期末复习

本仓库用于整理我**大三下学期期末考试**课程《软件项目管理》的复习资料。

其中：

- `软件项目管理题库.pdf`：课程老师在期末复习阶段发放的原始题库。
- `题库.md`：按照原始 PDF 内容整理的 Markdown 版本，便于在线阅读与检索。
- `答案.md`：我根据课程知识点整理的参考答案，包括选择题、判断题、填空题、简答题与综合应用题。

> 本仓库主要用于个人期末复习与知识整理。答案为本人整理的参考答案，如与课堂讲授内容或教师标准答案存在差异，请以课程教学要求为准。

## 仓库结构

```text
Software-Project-Management-Final-Review/
├── README.md
├── 软件项目管理题库.pdf
├── 题库.md
└── 答案.md
```

## 内容说明

题库主要包括以下五部分：

1. 单项选择题
2. 判断题
3. 填空题
4. 简答题
5. 综合应用题

答案部分尽量按照期末考试答题习惯整理：客观题给出明确答案和简要解析；简答题与综合应用题则在保留主要得分点的前提下尽量精简，便于考前复习和记忆。

## 使用建议

可以先使用 `题库.md` 独立练习，再对照 `答案.md` 检查。涉及 WBS、关键路径、PERT、项目生命周期、绩效域、估算方法等内容时，建议结合课堂讲义一起复习。
